# Примечания к выпуску ATBClone (Release Notes)

В этом документе зафиксированы все ключевые обновления, новые возможности, оптимизации и исправления ошибок для **ATBClone**.

---

## [v0.4.0] - 2026-08-19

### 🌐 Полная поддержка 9 языков для CLI и документации
- **Полная локализация интерфейса командной строки на 9 языков**:
  - Модуль `atbclone.core.i18n` расширен для полной поддержки английского, упрощенного китайского, традиционного китайского, японского, корейского, немецкого, французского, русского и испанского языков.
  - Все команды CLI (`wizard`, `clone`, `probe`, `list`, `recipe`, `doctor`, `update`, `remove`, `version`) выводят локализованные подсказки, таблицы и сообщения об ошибках.
- **Многоязычные примечания к выпуску**:
  - Стандартизирована документация по релизам на 9 языках в каталоге `docs/release/`.

### 🔄 Автоматизированный конвейер релизов и синхронизации версий
- **Автоматическая проверка примечаний к выпуску на 9 языках**:
  - Скрипты `scripts/manage_version.py` и `scripts/release.sh` обновлены для автоматической проверки наличия записей о версии во всех 9 файлах `docs/release/ReleaseNote*.md` перед созданием тега.
  - Добавлена опция `--check-notes` для проверки полноты документации.
- **Расширенный набор тестов**:
  - Набор автоматических тестов увеличен до 191 теста с полным покрытием многоязычности и процессов сборки.

---

## [v0.3.0] - 2026-08-19

### 🌐 Интернационализация и многоязычная поддержка (i18n)
- **Автоматическое определение системного языка macOS**:
  - Встроен модуль `atbclone.core.i18n`, автоматически считывающий языковые предпочтения интерфейса macOS через `AppleLanguages` и `AppleLocale`.
  - Динамическое переключение интерактивного мастера, командной строки, заголовков таблиц и сообщений об ошибках между русским, английским и китайским языками.
  - Поддержка ручного переопределения языка с помощью переменной окружения `ATBCLONE_LANG` (`ATBCLONE_LANG=en` / `ATBCLONE_LANG=zh`).
- **Многоязычная документация**:
  - Основной файл документации на английском языке (`Readme.md`) и китайская версия (`Readme_zh.md`).
  - Примечания к выпуску на 9 языках: английском, упрощенном китайском, традиционном китайском, японском, корейском, немецком, французском, русском и испанском.

### 🛠️ Улучшения интерфейса командной строки и сборки
- **Локализация мастера клонирования**: Полная поддержка мультиязычности в `atbclone wizard` (настраиваемые имена, выбор `.icns` и параметры прокси).
- **Автономный исполняемый файл**: Пересборка `./dist/ATBCloneCli` с помощью Nuitka со встроенными словарями и улучшенной совместимостью с песочницей (`PYTHONNOUSERSITE=1`).
- **Набор тестов**: Добавлен модуль `test_i18n.py`, успешно пройдены все 186 автоматических тестов.

## [v0.2.0] - 2026-08-18

### 🚀 Основные новые функции
- **Интерактивный мастер клонирования (`atbclone wizard`)**:
  - Пошаговое руководство в терминале с поддержкой перетаскивания (drag-and-drop) путей `.app`.
  - Автоматическая инкрементация названий клонов (например, `WeChat2`, `WeChat3`).
  - Поддержка пользовательских отображаемых имен и иконок приложений в формате `.icns`.
  - Интерактивная настройка выделенных сетевых прокси (HTTP и SOCKS5) с аутентификацией.
- **Интеллектуальный анализатор приложений (`atbclone probe`)**:
  - Автоматический анализ архитектуры Mach-O (arm64, x86_64, Universal), фреймворков (Electron, Flutter, Chromium, Qt, Cocoa) и прав песочницы (`com.apple.security.app-sandbox`).
  - Динамический подбор оптимальной стратегии (`hard_clone` или `soft_clone`) для сторонних приложений и генерация Recipe YAML.
  - Автоматический запуск анализатора в команде `atbclone clone` при отсутствии предустановленного рецепта.
- **Сборка единого бинарного файла**:
  - Добавлен скрипт `scripts/build_cli.sh` для компиляции полностью автономного исполняемого файла macOS arm64 (`dist/ATBCloneCli`) с помощью Nuitka.

### ⚡ Улучшения и исправления
- Повышение привилегий для каталога `/Applications` переведено на стандартный диалог авторизации `osascript` macOS.
- Комплексное экранирование путей с помощью `shlex.quote` для защиты от пробелов и специальных символов.

## [v0.1.0] - 2026-08-17

### 🌟 Первый официальный релиз
- **Двухдвижковая архитектура клонирования**:
  - **Hard Clone (Полный клон)**: Дублирование App Bundle, изменение `Info.plist`, изоляция каталогов `HOME` / `TMPDIR`, снятие песочницы и повторная ad-hoc подпись.
  - **Soft Clone (Легкий клон)**: Легковесный загрузчик для браузеров Chromium и редакторов кода с передачей `--user-data-dir`.
- **Более 18 встроенных рецептов**:
  - Мессенджеры: WeChat, QQ, Telegram, LINE, Slack, Discord, Skype.
  - ИИ-клиенты: ChatGPT (Codex), Gemini, Antigravity, Antigravity IDE.
  - Браузеры и редакторы: Google Chrome, Microsoft Edge, Firefox, Arc, Cursor, VS Code, Zed.
- **Команды CLI**:
  - `clone`: Создание клона приложения с настраиваемыми параметрами.
  - `list`: Просмотр списка клонов в виде таблицы Rich.
  - `update`: Обновление клона после апдейта основного приложения с сохранением данных.
  - `remove`: Безопасное удаление клона.
  - `recipe`: Просмотр и управление рецептами.
  - `doctor`: Проверка инструментов системы (`codesign`, `xcode-select`, `PlistBuddy`).
