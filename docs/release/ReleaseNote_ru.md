# Примечания к выпуску ATBClone (Release Notes)

В этом документе зафиксированы все ключевые обновления, новые возможности, оптимизации и исправления ошибок для **ATBClone**.

---

## [v0.9.4] - 2026-08-23

### 📁 Перенос каталога данных по умолчанию в `~/ATBClone`
- **Удобное управление данными**:
  - Каталог по умолчанию перенесен из скрытой папки `~/.atbclone` в видимый пользовательский каталог `~/ATBClone` (`~/ATBClone/Data/`, `~/ATBClone/clones.yaml`).
  - Упрощен поиск, резервное копирование и управление данными клонов в Finder и Терминале.

### 🏷️ Точное применение пользовательских имен клонов
- **Очистка локализованных строк**:
  - Автоматическое удаление `LSHasLocalizedDisplayName` и очистка `InfoPlist.strings` в `SoftCloneEngine` и `HardCloneEngine`.
  - Гарантирует отображение заданного пользователем имени в Finder, Dock, Spotlight и Мониторинге системы.

### 🔄 Автоматическая регистрация в LaunchServices
- **Мгновенное обновление кэша**:
  - Вызов `lsregister -f` после создания или обновления клона для немедленного обновления иконок и информации без перезагрузки системы.

### 📦 Документация и тесты
- **Синхронизация**:
  - Обновление справочных материалов, интерфейса настроек и всех 341 автоматических тестов.

## [v0.9.3] - 2026-08-21

### 🛡️ Улучшенный анализ приложений и предупреждения в мастере
- **Предварительная проверка iOS-on-Mac приложений**:
  - Обновлен метод `AppInspector.inspect_app` для мгновенного анализа `UIDeviceFamily` / `LSRequiresIPhoneOS` при выборе или перетаскивании файла приложения.
  - В мастере создания GUI (`WizardWindow`) при выборе неподдерживаемого iOS-приложения сразу появляется информативное диалоговое окно, а поле ввода сбрасывается.

### 🍏 Корректное завершение работы в macOS и очистка Cocoa-объектов
- **Предотвращение сбоев при выходе (Crash on Exit)**:
  - Улучшены методы `TrayService.disable()` и `ATBCloneApp.exit_app()` для безопасного отключения таргетов и селекторов статусной строки Cocoa перед закрытием.
  - Реализован чистый выход из цикла событий Cocoa (`NSApp.terminate_` / `os._exit(0)`), устранивший падения программы при выходе через системный трей или `Cmd+Q`.

### 📦 Тесты
- **Расширение набора тестов**:
  - Набор тестов увеличен до 341 автоматического теста.

## [v0.9.2] - 2026-08-21

### 🍏 Динамическое скрытие иконки в macOS Dock и оптимизация трея
- **Автоматическое управление иконкой в Dock**:
  - Реализовано динамическое скрытие и отображение иконки в Dock с помощью политик активации AppKit (`NSApplicationActivationPolicy`).
  - При сворачивании или закрытии окна в системный трей иконка в Dock автоматически скрывается (`NSApplicationActivationPolicyAccessory`).
  - При восстановлении окна из строки меню иконка в Dock мгновенно возвращается (`NSApplicationActivationPolicyRegular`), а окно получает фокус.
- **Обработчик клика по иконке в Dock (Reopen Handler)**:
  - Добавлен метод `applicationShouldHandleReopen:hasVisibleWindows:` в `AppDelegate` для плавного открытия главного окна при клике на приложение в Dock.

### 📦 Оптимизация ресурсов и тесты
- **Сжатие иконок**:
  - Проведена оптимизация файлов иконок (`logo.icns` и `logo.png`), уменьшившая размер дистрибутива.
- **Тесты**:
  - Набор тестов увеличен до 338 автоматических тестов.
