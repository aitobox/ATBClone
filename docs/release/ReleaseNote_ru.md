# Примечания к выпуску ATBClone (Release Notes)

В этом документе зафиксированы все ключевые обновления, новые возможности, оптимизации и исправления ошибок для **ATBClone**.

---

## [v0.8.0] - 2026-08-20

### 🎨 Визуальное обновление в соответствии с macOS HIG
- **Нативный дизайн Apple и повышенная доступность**:
  - Полная переработка графического интерфейса в соответствии с Apple Human Interface Guidelines (HIG): единая палитра системных цветов, иерархия шрифтов (11pt–22pt) и комфортные отступы.
  - Улучшенное отображение таблиц Cocoa через патчинг во время выполнения (`patch_cocoa`): высота строк увеличена до 40px, обновлены заголовки и увеличен шрифт содержимого.
  - Увеличены размеры полей ввода, выпадающих списков, переключателей, кнопок и меток в мастере, настройках и окнах редактирования.
  - Панели действий под таблицами приведены к компактному стилю панели инструментов macOS.
  - По умолчанию включен режим **Таблицы (List View)** во всех разделах управления.

### 💾 Единое управление хранилищем и автосинхронизация путей
- **Оптимизация настроек хранилища**:
  - Реорганизация `SettingsView`: изменение корневой папки хранилища автоматически синхронизирует пути всех подкаталогов (`clones.yaml`, `Data/`, `logs/`, `recipes/`).
  - Отображение статуса доступности путей в реальном времени.

### 🌐 Поддержка протокола HTTPS-прокси
- **Расширенная поддержка прокси**:
  - Полная поддержка схем `https://` в моделях рецептов, CLI (`atbclone clone`, `atbclone wizard`) и настройках сети GUI.

### 📦 Улучшения сборки приложений и расширение тестов
- **Точка входа модуля и упаковка DMG**:
  - Добавлен файл `src/atbclone/__main__.py` для прямого запуска через `python -m atbclone`.
  - Улучшен скрипт сборки `scripts/build_gui.sh` с проверкой целостности пакета приложения, ресурсов и подписи.
- **Тесты**:
  - Набор тестов увеличен до 304 автоматических тестов GUI и ядра.

## [v0.7.0] - 2026-08-20

### 🖥️ Нативное настольное приложение с графическим интерфейсом BeeWare Toga
- **Современный интерфейс в стиле Ice-Blue**:
  - Выпущено полноценное нативное настольное приложение для macOS (`atbclone-gui`) на базе BeeWare Toga.
  - Удобная боковая панель и карточная сетка: управление клонами (`ClonesView`), глубокий анализ (`ProbeView`), рецепты (`RecipesView`), просмотр журналов (`LogsView`) и настройки (`SettingsView`).
  - Интерактивный визуальный мастер создания клонов с поддержкой перетаскивания файлов `.app`.

### 🍏 Системный трей в строке меню macOS и сворачивание
- **Интеграция со строкой меню (TrayService)**:
  - Нативная интеграция с `NSStatusBar` и `NSStatusItem` с быстрым меню (Открыть, Создать клон, Быстрый запуск, Настройки, Выход).
  - Опция «Сворачивать в строку меню» с плавным скрытием и восстановлением через селекторы Cocoa и `NSWindowDelegate`.

### 📖 Встроенный многоязычный просмотрщик примечаний к выпуску
- **Окно истории версий**:
  - Доступ к истории версий прямо из панели настроек приложения.
  - Динамический переключатель на 9 языков с отображением Markdown в реальном времени.

### 📝 Единая система журналов операций (Unified Logger)
- **Сохранение в файл и прямой эфир событий**:
  - Реализован модуль `atbclone.core.logger` для объединения журналов CLI и GUI (`~/.atbclone/logs/atbclone.log`) с потоковой трансляцией (`LogBroadcastHandler`).
  - Окно просмотра журналов в GUI с фильтрацией по уровням, поиском, экспортом и очисткой.

### 📦 Расширение каталога рецептов и тесты
- **Новые встроенные рецепты**: Добавлены и обновлены рецепты для **Claude Desktop** (`com.anthropic.claudefordesktop`), **Telegram** (`ru.keepcoder.Telegram`), **Cursor** и других.
- **Расширенный набор тестов**: Набор тестов увеличен до 299 автоматических тестов GUI и модулей ядра.

## [v0.6.0] - 2026-08-19

### 📂 Поддержка пользовательских каталогов данных
- **Настраиваемое расположение данных клона (`--data-dir`)**:
  - Добавлена опция `--data-dir` для команды `atbclone clone`, позволяющая указывать путь к каталогу данных (например, на внешнем SSD или в рабочей папке).
  - Интеграция настройки каталога данных в интерактивный мастер (`atbclone wizard`).
  - Поддержка динамических переменных каталога данных в моделях рецептов и движках клонирования.

### 🗑️ Улучшенное удаление клонов и очистка данных (`atbclone remove`)
- **Управление очисткой данных при удалении**:
  - Добавлен флаг `--purge-data` для команды `atbclone remove` для полного удаления приложения и связанных каталогов данных.
  - Добавлен флаг `--keep-data` для удаления только приложения с сохранением пользовательских данных.
  - Интерактивный диалог подтверждения с понятным выбором между сохранением и удалением данных.
  - Улучшена обработка потерянных каталогов и ошибок прав доступа.

### 🆔 Стандартизация Bundle ID и многоязычность
- **Единый формат генерации Bundle ID**:
  - Добавлен метод `AppInspector.generate_bundle_id`, обеспечивающий идентичный формат Bundle ID для команд `clone`, `wizard` и `update`.
- **Локализация**:
  - Полный перевод всех новых диалогов, запросов каталогов и сообщений на все 9 поддерживаемых языков.
- **Тесты**:
  - Набор тестов увеличен до 213 автоматических тестов.

## [v0.5.0] - 2026-08-19

### 🔐 Подпись кода Apple и нотаризация (Notarization)
- **Усиленная среда выполнения (Hardened Runtime) и официальная подпись**:
  - Интеграция подписи сертификатом Apple Developer ID Application с опцией Hardened Runtime (`--options runtime`), временными метками и файлом разрешений JIT (`scripts/entitlements.plist`).
  - Новый скрипт `scripts/notarize.sh` для автоматической нотаризации через `xcrun notarytool` с использованием профилей связки ключей (`--keychain-profile`).
  - Поддержка флагов `--sign-identity`, `--skip-sign` и `--notarize` в скриптах `scripts/build_cli.sh` и `scripts/release.sh` с автоматическим переходом на ad-hoc подпись.

### 🚀 Жесткое клонирование Chromium и передача аргументов запуска
- **Поддержка аргументов запуска в `HardCloneEngine`**:
  - Улучшен `HardCloneEngine` для динамической вставки аргументов вида `--user-data-dir={{ATB_DATA_DIR}}` в скрипт запуска наряду с переменными окружения.
  - Встроенные рецепты для **Google Chrome**, **Microsoft Edge** и **Arc Browser** переведены на стратегию `hard_clone` для полной изоляции App Bundle в Dock и Finder.
- **Переопределение стратегии в CLI**:
  - Добавлена опция `--strategy` (`hard_clone` / `soft_clone`) для команды `atbclone clone`.

### ⚡ Оптимизация процессов и расширение тестов
- **Перенаправление процессов**: Оптимизация скрипта запуска `SoftCloneEngine` с использованием стандартного `exec "$@"`.
- **Расширенный набор тестов**: Набор тестов увеличен до 199 автоматических тестов с покрытием подписи кода и нотаризации.

## [v0.2.0] - 2026-08-18

### 🚀 Основные новые функции
- **Интерактивный мастер клонирования (`atbclone wizard`)**:
  - Пошаговое руководство в терминале с поддержкой перетаскивания (drag-and-drop) путей `.app`.
  - Автоматическая инкрементация названий клонов (например, `WeChat2`, `WeChat3`).
  - Поддержка пользовательских отображаемых имен и иконок приложений в формате `.icns`.
  - Интерактивная настройка выделенных сетевых прокси (HTTP и SOCKS5) с аутентификацией.
- **Интеллектуальный анализатор приложений (`atbclone probe`)**:
  - Автоматический анализ архитектуры Mach-O (arm64, x86_64, Universal), фреймворков (Electron, Flutter, Chromium, Qt, Cocoa) и прав песочницы (`com.apple.security.app-sandbox`).
  - Динамический подбор оптимальной стратегии (`hard_clone` или `soft_clone`) для сторонних приложений и генерация Recipe YAML.
  - Автоматический запуск анализатора в команде `atbclone clone` при отсутствии предустановленного рецепта.
- **Сборка единого бинарного файла**:
  - Добавлен скрипт `scripts/build_cli.sh` для компиляции полностью автономного исполняемого файла macOS arm64 (`dist/ATBCloneCli`) с помощью Nuitka.

### ⚡ Улучшения и исправления
- Повышение привилегий для каталога `/Applications` переведено на стандартный диалог авторизации `osascript` macOS.
- Комплексное экранирование путей с помощью `shlex.quote` для защиты от пробелов и специальных символов.

## [v0.1.0] - 2026-08-17

### 🌟 Первый официальный релиз
- **Двухдвижковая архитектура клонирования**:
  - **Hard Clone (Полный клон)**: Дублирование App Bundle, изменение `Info.plist`, изоляция каталогов `HOME` / `TMPDIR`, снятие песочницы и повторная ad-hoc подпись.
  - **Soft Clone (Легкий клон)**: Легковесный загрузчик для браузеров Chromium и редакторов кода с передачей `--user-data-dir`.
- **Более 18 встроенных рецептов**:
  - Мессенджеры: WeChat, QQ, Telegram, LINE, Slack, Discord, Skype.
  - ИИ-клиенты: ChatGPT (Codex), Gemini, Antigravity, Antigravity IDE.
  - Браузеры и редакторы: Google Chrome, Microsoft Edge, Firefox, Arc, Cursor, VS Code, Zed.
- **Команды CLI**:
  - `clone`: Создание клона приложения с настраиваемыми параметрами.
  - `list`: Просмотр списка клонов в виде таблицы Rich.
  - `update`: Обновление клона после апдейта основного приложения с сохранением данных.
  - `remove`: Безопасное удаление клона.
  - `recipe`: Просмотр и управление рецептами.
  - `doctor`: Проверка инструментов системы (`codesign`, `xcode-select`, `PlistBuddy`).
